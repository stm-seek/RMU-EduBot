## กฎ 3 ข้อสำหรับคนเขียนเล่ม

1. **ห้ามเชื่อ `README.md` ที่รากโปรเจกต์เป็นข้อเท็จจริง** — เขียนไว้ตั้งแต่กลางเดือน
   แล้วยังไม่ได้อัปเดตตามโค้ด บางข้อ (เช่น "ยังไม่มี FAQ matching",
   "ยังไม่ได้รันบน Postgres จริง", วิธีล็อกอิน admin) **ล้าสมัยไปแล้ว**
   ตัวเลขและสถานะที่ถูกต้องอยู่ในคู่มือชุดนี้
2. **เขียนเท่าที่ระบบทำได้จริง** ระบบนี้ออกแบบมาให้ "ไม่รู้ก็บอกว่าไม่รู้"
   ถ้าเล่มเคลมเกิน กรรมการกดปุ่มเดียวก็เจอ — ดู [09-thesis-map.md](09-thesis-map.md)
   หัวข้อ "สิ่งที่ห้ามเคลม"
3. **ตัวเลขทุกตัวมีที่มา** ถ้าจะใส่ตัวเลขในเล่ม ให้เอาจากคู่มือนี้หรือรันคำสั่งดูเอง
   (ทุกหัวข้อบอกคำสั่งไว้) อย่าปัดเศษให้สวยแล้วเขียนเอง
