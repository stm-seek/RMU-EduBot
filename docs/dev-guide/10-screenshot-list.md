## เคล็ดลับตอนแคป

- **ตัดข้อมูลส่วนตัวออกทุกภาพ** — `user_hash`, channel secret, access token,
  API key, URL ของทันเนล, อีเมลอาจารย์ที่เป็นโดเมนส่วนตัว
- ตั้งชื่อรูปในเล่มเป็น "ภาพที่ 4-1 …" แล้วทำตารางแม็ปกับชื่อไฟล์ในโฟลเดอร์นี้
  จะแก้ภาพทีหลังง่ายมาก
- ภาพเทอร์มินัลให้ขยายฟอนต์ก่อนแคป (`Ctrl + Shift + +`) ไม่งั้นพิมพ์เล่มออกมาอ่านไม่ออก
- ถ้าคอนโซลแสดงภาษาไทยเป็น `?????` ยังไม่ได้ตั้ง `$env:PYTHONUTF8="1"`
  (ดู [08-pitfalls.md](08-pitfalls.md))
- แคปหน้าเว็บเต็มหน้าใน Chrome: `F12` → `Ctrl+Shift+P` → พิมพ์
  `Capture full size screenshot`
- **อยากได้แผนภาพกลุ่ม C ใหญ่กว่าเดิม/แก้ข้อความ** — เปิด `diagrams/<ชื่อ>.html`
  ในเบราว์เซอร์ แก้บรรทัด `.mermaid{zoom:...}` ให้ใหญ่ขึ้น หรือแก้ข้อความในบล็อก
  `<pre class="mermaid">` ได้เลย แล้วแคปด้วย `Capture full size screenshot`
  (ต้องต่อเน็ตครั้งแรกเพราะโหลด Mermaid จาก CDN)
