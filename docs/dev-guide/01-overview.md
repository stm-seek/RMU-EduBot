# 01 — ภาพรวมระบบ

## 1.1 ระบบนี้แก้ปัญหาอะไร

นักศึกษาต้องถามเรื่องซ้ำ ๆ กับอาจารย์ที่ปรึกษาและเจ้าหน้าที่ (ลงวิชาอะไรดี
ต้องใช้เอกสารอะไร ติดต่ออาจารย์คนไหน จบทันไหม) ข้อมูลกระจายอยู่หลายเว็บของ
มหาวิทยาลัยและบางส่วนต้องล็อกอินระบบทะเบียน ระบบนี้รวมข้อมูลสาธารณะเหล่านั้น
มาไว้ที่เดียว แล้วให้ตอบผ่าน LINE ซึ่งเป็นแอปที่นักศึกษาใช้อยู่แล้ว

**หลักการที่ยึดตลอดทั้งระบบ:** เรื่องที่คำนวณได้แน่นอน (หน่วยกิต วิชาบังคับก่อน
ตารางชน เกรด) ใช้ **โค้ดคำนวณ ไม่ให้ AI คิด** — AI ทำหน้าที่เรียบเรียงคำอธิบาย
จากผลที่คำนวณแล้วเท่านั้น และถ้าไม่มีข้อมูลอ้างอิง **ตอบว่าไม่มี ไม่เดา**

## 1.3 ยังไม่ได้ทำ / ติดที่ข้อมูล ไม่ใช่ติดที่โค้ด

| เรื่อง | ติดอะไร |
|---|---|
| `prerequisites` (วิชาบังคับก่อน) | **ตารางว่างทั้งตาราง** — ระบบทะเบียนไม่เผยแพร่ข้อมูลนี้ และไม่มี มคอ.2 ออนไลน์ ต้องขอเล่มจากคณะแล้วกรอกผ่าน `/admin` |
| RAG (ชั้น 3 เต็มรูปแบบ) | ตาราง `rag_chunks` ว่าง — ยังไม่มีเนื้อหาทางการที่จะ index (ระเบียบ/ข้อบังคับ) โครงสร้าง pgvector พร้อมแล้ว |
| เนื้อหา FAQ | กลไกเสร็จ แต่ต้องให้คณะเขียนคำตอบเอง ห้ามแต่งเอง |
| หลักสูตรอื่นของคณะ IT | มีแผนการเรียนครบแค่ 643170151 (คณะมีอีก 6 หลักสูตร) |
| เบอร์โทร/ห้องพักอาจารย์ | เว็บคณะไม่มีข้อมูล (0/28 คน) ต้องกรอกมือ |
| ข้อมูลกิจกรรม (จิตอาสา) | `e-activity.rmu.ac.th` คืน HTTP 500 ทุก path |
| สเกลเกรด/เกณฑ์เกียรตินิยม | คำนวณได้แล้วแต่ยังไม่ได้ยืนยันตัวเลขกับเล่มข้อบังคับ RMU |

## 1.5 สิ่งที่ระบบตั้งใจไม่เก็บ (PDPA)

| เก็บ | ไม่เก็บ |
|---|---|
| `line_user_hash` (SHA-256 + pepper) | LINE user id ดิบ |
| รหัสหลักสูตร, ชั้นปี | ชื่อ-นามสกุล, รหัสนักศึกษา |
| รายการ**รหัสวิชา**ที่ผ่านแล้ว | **เกรดรายวิชา**, เลขบัตรประชาชน, รหัสผ่านระบบทะเบียน |

ระบบ **ไม่ขอรหัสผ่านระบบทะเบียนของนักศึกษา** โดยเจตนา (เดิมมีแผน A ที่ล็อกอินแทน
นักศึกษา — ยกเลิกแล้ว โค้ดทดลองเก็บไว้ในโฟลเดอร์ `test/` และล้าง credential ออกแล้ว)
