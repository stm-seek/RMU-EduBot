# 04 — ฐานข้อมูล

**Postgres 17 + pgvector + pg_trgm** รันในเครื่องผ่าน Docker
(image `pgvector/pgvector:pg17`, container `rmu_bot_db`, bind แค่ `127.0.0.1`
ไม่เปิดออกเน็ต) — **ยืนยันแล้วว่ารันบน Postgres จริงผ่าน** ไม่ใช่แค่ตรวจ syntax

## 4.1 ตาราง 22 ตาราง แบ่งเป็น 6 กลุ่ม

> ER diagram ของตารางหลัก 13 ตาราง (ความสัมพันธ์ตรงตาม foreign key จริง)
> อยู่ที่ `screenshots/c03-er-diagram.png` แก้ต้นฉบับได้ที่ `diagrams/c03-er-diagram.html`

**กลุ่ม 1 — หลักสูตรและรายวิชา (ข้อมูลจาก scraper)**

| ตาราง | เก็บอะไร |
|---|---|
| `programs` | หลักสูตร (รหัส ชื่อ คณะ ระดับ หน่วยกิตรวม) |
| `categories` | หมวดวิชาในหลักสูตร (ศึกษาทั่วไป เฉพาะด้าน เลือกเสรี ฯลฯ) |
| `courses` | รายวิชา + คำอธิบายรายวิชา + หน่วยกิต |
| `program_courses` | วิชาใดอยู่หมวดใดของหลักสูตรใด (ตารางเชื่อม) |
| `curriculum_rules` | **แผนการเรียนมาตรฐาน 8 เทอม** — input หลักของ Planner |
| `prerequisites` | วิชาบังคับก่อน — **ยังว่างทั้งตาราง** (ไม่มีแหล่งข้อมูล) |

**กลุ่ม 2 — การเปิดสอนและตารางเรียน**

| ตาราง | เก็บอะไร |
|---|---|
| `offerings` | หมู่เรียนที่เปิดในแต่ละเทอม (อาจารย์ ที่นั่ง ที่นั่งเหลือ) |
| `offering_slots` | คาบเรียน (วัน เวลา ห้อง) — ใช้ตรวจตารางชน |
| `offering_patterns` | รูปแบบการเปิดสอนที่พบซ้ำ ๆ ใช้คาดการณ์ว่าวิชาน่าจะเปิดเทอมไหน |

**กลุ่ม 3 — ข้อมูลบริการนักศึกษา**

| ตาราง | เก็บอะไร |
|---|---|
| `documents` | เอกสาร/แบบฟอร์ม/คำร้อง 33 ฉบับ 11 หมวด + ลิงก์ไฟล์จริง |
| `instructors` | อาจารย์ 28 คน (ชื่อ ตำแหน่ง อีเมล) |
| `instructor_affiliations` | สังกัด/สาขาของอาจารย์ (คนหนึ่งมีได้หลายสังกัด) |

**กลุ่ม 4 — ผู้ใช้ (ข้อมูลที่ผ่าน PDPA แล้ว)**

| ตาราง | เก็บอะไร |
|---|---|
| `app_users` | `line_user_hash` (SHA-256 + pepper), หลักสูตร, ชั้นปี — **ไม่มีชื่อ ไม่มีรหัสนักศึกษา** |
| `user_completed_courses` | รหัสวิชาที่ผู้ใช้ติ๊กว่าผ่านแล้ว — **ไม่เก็บเกรด** |
| `liff_sessions` | session ของหน้า LIFF |
| `ai_sessions` | สถานะโหมดปรึกษา AI (จำนวนตา เวลาหมดอายุ) |

**กลุ่ม 5 — คลังคำตอบ**

| ตาราง | เก็บอะไร |
|---|---|
| `faqs` | คำถาม-คำตอบที่คนเขียนเอง + `variants` (คำถามรูปแบบอื่น) — ชั้นที่ 2 |
| `rag_chunks` | ชิ้นเนื้อหา + เวกเตอร์ (`vector(768)`) สำหรับ RAG — **ยังว่าง** |

**กลุ่ม 6 — บันทึกการทำงาน / ผู้ดูแล**

| ตาราง | เก็บอะไร |
|---|---|
| `chat_logs` | ทุกบทสนทนา + `answered_by` + สถานะ — **ใช้วัดผลในบทที่ 4-5** |
| `scrape_runs` | ประวัติการดึงข้อมูลแต่ละรอบ (ใช้ตรวจว่าข้อมูลเก่าแค่ไหน) |
| `admin_accounts` | บัญชีผู้ดูแลหน้า `/admin` (username + scrypt hash) |
| `admin_audit_logs` | ใครแก้อะไรในหน้า `/admin` เมื่อไร |

## 4.2 ไฟล์ migration (รันตามลำดับเลข)

| ไฟล์ | เพิ่มอะไร |
|---|---|
| `001_init.sql` | schema หลัก 19 ตาราง + index + เปิด extension `vector`, `pg_trgm` |
| `002_ai_sessions.sql` | ตาราง `ai_sessions` (โหมดปรึกษา AI) |
| `003_answered_by_values.sql` | เพิ่มค่า `answered_by` + **แก้ป้ายของ 21 แถวเก่าที่ป้ายผิด** |
| `004_chat_log_status.sql` | สถานะของ `chat_logs` (สำเร็จ/ล้มเหลว) |
| `005_planner.sql` | คอลัมน์ที่ Planner ต้องใช้ + `curriculum_rules` |
| `006_admin.sql` | คอลัมน์ `is_active` + `admin_audit_logs` สำหรับหน้า `/admin` |
| `007_answered_by_faq.sql` | เพิ่มค่า `faq` เข้า CHECK constraint ของ `chat_logs` |
| `008_admin_accounts.sql` | ตาราง `admin_accounts` — เปลี่ยนวิธีล็อกอิน admin จาก LINE Login มาเป็น username/password |

`chat_logs.answered_by` มี **CHECK constraint** คุมค่าที่ใส่ได้ → เพิ่มป้ายใหม่ใน
โค้ดต้องเพิ่ม migration ด้วย ไม่งั้น INSERT พังทั้งแถว (ป้ายใหม่ตัวล่าสุดคือ `faq`)

## 4.3 ข้อมูลตั้งต้น (seed)

| ไฟล์ | เนื้อหา |
|---|---|
| `db/seed/002_seed_data.sql` | 1,066 แถวจาก scraper — **เป็นไฟล์ generated ห้ามแก้ด้วยมือ** ต้องแก้ที่ `db/export_seed.py` แล้ว export ใหม่ |
| `db/seed/003_curriculum_rules.sql` | แผนการเรียน 8 เทอม 32 วิชาของ 643170151 (แปลงจากไฟล์แผนการเรียนของคณะ) |

seed ทุกไฟล์เป็น **idempotent** (ใช้ `ON CONFLICT ... DO UPDATE`) รันซ้ำได้ไม่พัง
— ข้อนี้เคยเป็นบั๊ก แก้แล้วและมีเทสคุมไว้

## 4.4 เครื่องมือตรวจฐานข้อมูลที่เขียนไว้เอง

| สคริปต์ | ตรวจอะไร |
|---|---|
| `db/validate_sql.py` | syntax ของทุกไฟล์ SQL ด้วย `sqlglot` (ไม่ต้องมี Postgres) |
| `db/check_integrity.py` | FK / constraint / **ลำดับ INSERT** ว่าอ้างแถวที่ยังไม่มีหรือไม่ |
| `db/export_seed.py` | แปลง SQLite ของ scraper → SQL ของ Postgres |
| `scripts/import_curriculum_rules.py` | นำเข้าแผนการเรียน + **นับจำนวนวิชาก่อน/หลังให้ตรงกัน** (เคยหายไปเงียบ ๆ 1 วิชา) |

## 4.5 ข้อมูลส่วนบุคคลในไฟล์ seed (ต้องรู้ก่อนเปิด repo ให้คนอื่น)

`db/seed/002_seed_data.sql` มี **ชื่อจริงอาจารย์ 28 คน + อีเมลจริง 26 รายการ**
(`@rmu.ac.th` 16, gmail 7, hotmail 3) — เก็บไว้ได้เพราะ repo เป็น **private**
และเว็บคณะเผยแพร่ข้อมูลชุดนี้สาธารณะอยู่แล้ว

⚠️ **ถ้าจะเปลี่ยน repo เป็น public หรือส่งไฟล์นี้ออกไปข้างนอก ต้องปิดบังอีเมล
โดเมนส่วนตัว 10 รายการก่อน** แก้ที่ `db/export_seed.py` แล้ว export ใหม่
(ห้ามแก้ `002_seed_data.sql` ด้วยมือ)
